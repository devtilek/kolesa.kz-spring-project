# Kolesa Spring Project

Это простое веб-приложение на Spring Boot, которое позволяет управлять данными о автомобилях и странах. 
В проекте реализован базовый CRUD функционал (создание, чтение, обновление, удаление) для сущностей Car и Country.

## Технологии
- Java 25
- Spring Boot
- Spring MVC
- Spring Data JPA / Hibernate
- Thymeleaf
- PostgreSQL
